# GitHub Upload Steps

1. Create a new public GitHub repository.
2. Repository name: risk-aware-uav-mission-planner
3. Description: A simple Python project for UAV mission planning with risk zones and battery feasibility.
4. Keep Add README turned off.
5. Upload these files:
   - README.md
   - uav_mission_planner.py
   - mission_points.csv
   - risk_zones.csv
   - uav_parameters.csv
   - GITHUB_UPLOAD_STEPS.md
6. Commit changes.
